# 개인정보 처리 원칙

1. 문의 원문과 개인정보는 로컬에서만 처리한다. 외부 API로는 보내지 않는다.
2. 외부 LLM(선택 기능)에는 이름이 `[NAME]`으로 가려진 응대문만 보낸다. 실제 이름은 응답을 받은 뒤 로컬에서 채운다.
3. 저장소에는 가상 데이터만 둔다. `.gitignore`가 `.env`, `data/private/`, CAD 파일(stl/step/3mf/obj)을 막는다.
4. 가격 규칙은 데모용 예시값이며 실제 원가표가 아니다.

## 알려진 한계

- `pii_filter`는 정규식 휴리스틱이라 모든 이름·주소를 잡지 못한다. 실서비스에서는 NER 또는 로컬 LLM 2차 검사가 필요하다.
- 문의 본문에 이름이 `저는 OOO입니다`, `이름: OOO`, `OOO 드림` 형태가 아니면 분리되지 않는다.
