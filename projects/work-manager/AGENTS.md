# 김명규크리에이티브 작업 및 에이전트 개발 가이드 (AGENTS.md)

이 문서는 김명규크리에이티브의 3D 프린팅·적층제조 사업 운영과 작업관리웹 시스템 개발 시 에이전트(Codex/Antigravity)가 반드시 준수해야 하는 **에이전트 작업 행동 강령** 및 **사업 운영 기준**이다.

---

## Ⅰ. 에이전트 작업 행동 강령 (코드 수정 및 탐색 원칙)

### 1. 최소 탐색 및 범위 한정 원칙 (Strict Scope Limitation)
- 사용자가 특정 기능이나 파일의 수정을 요청하면 **프로젝트 전체를 무단으로 탐색/리뷰하지 않는다.**
- 작업 시작 시 **`docs/CODEMAP.md`를 가장 먼저 확인**하여 수정 대상 기능에 매핑된 파일만 선별한다.
- 최초 탐색 범위는 **관련 파일 3~5개 이내**로 엄격히 제한한다.
- 정보가 부족하다는 이유만으로 전체 디렉터리(`list_dir`), 광범위한 `grep_search`를 남발하지 않는다.
- 사용자가 특정 파일명이나 기능을 명시한 경우, 이를 **탐색 범위의 최우선 제한 조건**으로 취급한다.

### 2. 단계적 의존성 확장 (Step-by-Step Expansion)
- 현재 열려있는 3~5개 파일만으로 작업이 불가능하거나 정의되지 않은 함수/모듈이 있을 때만 **한 단계씩 의존 파일을 확장**한다.
- **관심사 분리 철저 준수**:
  - 단순 UI/CSS 수정 시 → DB, AI, PDF 엔진, 배포 코드 등 무관한 백엔드 코드를 열람하지 않는다.
  - 견적서 엑셀 수식 수정 시 → 로지아이 택배, Three.js 뷰어 코드를 열람하지 않는다.
  - 파일 다운로드/업로드 수정 시 → 대시보드 차트나 AI 프롬프트 코드를 열람하지 않는다.

### 3. 작업 후 전체 리뷰 금지 & 타깃 검증 (Targeted Verification)
- 코드 수정 완료 후 전체 저장소를 다시 읽거나 불필요한 전체 재검색을 수행하지 않는다.
- 검증은 수정된 파일과 직접 관련된 기능(해당 엔드포인트 curl 테스트, 프론트엔드 모달 렌더링, 특정 함수 단위 테스트 등)만 집중 수행한다.
- 코드 구조나 파일 경로가 변경된 경우에만 **`docs/CODEMAP.md`를 동기화 업데이트**한다.

---

## Ⅱ. 표준 작업 절차 (Workflow)

1. **사용자 요청 분석**: 수정할 기능 및 대상 영역 식별
2. **`docs/CODEMAP.md` 확인**: 해당 기능의 `UI → API → Core → Data/DB` 매핑 경로 확인
3. **최소 파일 로드**: CODEMAP에 명시된 1~3개 핵심 파일만 열람
4. **코드 수정**: 기존 주석 및 아키텍처 보존하며 변경 적용
5. **국소 검증**: 변경된 API/UI 부분만 동작 확인
6. **문서 동기화**: 신규 파일 추가 또는 구조 변경 시 `docs/CODEMAP.md` 갱신

---

## Ⅲ. 김명규크리에이티브 사업 운영 원칙

### 1. 기본 정보 및 프로젝트 식별
- **사업명**: 김명규크리에이티브 (3D 프린팅, 시제품 제작, 슬라이싱 대행)
- **표준 위치**: `~/사업/10_프로젝트/<연도>/<프로젝트번호>_<고객명>_<작업명>/`
- **완료 위치**: `~/사업/20_완료/<연도>/` (제작+배송+입금 모두 완료 시에만 이동)
- **프로젝트 번호 체계**: `YYMMDD-NNN` (예: `260820-001`, 당일 순번 자동 채번)
- **개인정보 보호**: 고객 전화번호, 주소, 계좌번호는 폴더명이나 공개 파일명에 포함하지 않음.

### 2. 표준 7대 하위 폴더 구조
```text
~/사업/10_프로젝트/<연도>/<프로젝트번호>_<고객명>_<작업명>/
├── 00_작업정보/          # 작업정보.md (고객정보, 세부 품목 표, 출력 조건)
├── 01_수신원본/          # 고객 접수 카톡/이메일 원본 파일 (STL, STEP, 이미지 등)
├── 02_모델수정/          # 오류 수정 및 치수 보정된 CAD/STL 파일
├── 03_슬라이싱_3MF/      # Bambu Studio 실제 출력용 3MF 슬라이싱 프로젝트 파일
├── 04_출력검수/          # 완성 사진, 불량 분석, QC 사진
├── 05_견적거래/          # 발행된 견적서/거래명세서 엑셀(.xlsx) 및 PDF
└── 06_배송/              # 로지아이 예약 정보, 송장 PDF, 배송 패키징 사진
```

### 3. Bambu Studio 3MF 슬라이싱 연동 규칙
- 프로젝트 등록 시 `03_슬라이싱_3MF/` 폴더에 `data/templates/bambu_base_template.3mf` 기반의 초기 3MF 파일이 자동 생성된다.
- 3MF 파일명 규칙: `P01_제품명_소재_색상_Q수량_예상출력시간_v01.3mf`
- Bambu Studio에서 열었을 때 파일 경로가 고정되어 `Cmd + S`로 즉시 덮어쓰기 저장되어야 한다.

### 4. 3단계 분리 상태 관리
- **제작 상태**: `접수` → `슬라이싱` → `견적 대기` → `출력 중` → `검수` → `제작 완료`
- **결제 상태**: `미청구` → `견적 발송` → `입금 대기` → `부분 입금` → `입금 완료`
- **배송 상태**: `미정` → `예약 필요` → `예약 완료` → `발송` → `배송 완료`
- **전체 완료 조건**: `제작 완료` + `배송 완료` + `입금 완료`

### 5. 견적 및 운영대장 동기화
- **기본 출력 단가**: 시간당 3,500원 (별도 단가 미지정 시) / 기본 배송비: 3,500원
- 모든 프로젝트 생성/수정/삭제는 `00_운영/김명규크리에이티브_운영대장.xlsx` 및 SQLite DB(`data/app.db`)에 실시간 동기화된다.
